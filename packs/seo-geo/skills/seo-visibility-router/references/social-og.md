
## Use this when

The user wants better link previews, share cards, social CTR, or OG image strategy.

## What good social preview work should produce

- a good title
- a strong preview image
- correct metadata
- clean share behavior
- a faster path from impression to click

## What to examine

- Open Graph title/description
- OG image composition
- Twitter/X card metadata
- canonical URL
- mobile preview behavior

## Useful outputs

- metadata rewrite
- image strategy
- preview checklist
- share-card QA notes

## Human check

If the preview looks bad in one major platform, it is not done.
