
This reference is the high-level map for the pack.

## Use it when

- the user is asking which SEO/GEO workflow applies
- the user wants a broad view of the SEO tool landscape
- you need to decide whether the task is research, optimization, analysis, or monitoring

## Main buckets

- keyword research
- content optimization
- backlink / authority analysis
- rank tracking
- technical SEO
- local SEO
- social / Open Graph
- AI search visibility / GEO
- miscellaneous support tools

## Routing rule of thumb

If the request is about:
- what to target → keyword research
- how to improve a page → content optimization
- why authority is weak → backlink / authority analysis
- whether rankings moved → rank tracking
- why a site is broken for search → technical SEO
- how a location should rank → local SEO
- how a page shares on social → social / Open Graph
- how a brand appears in AI answers → AI search visibility / GEO

## Human check

If the request sounds vague, stop and ask:
- Are we trying to find opportunities, improve a page, fix a site issue, or measure visibility?
