
## Use this when

The user wants to improve an existing page, brief new content, or make a page more useful to search engines and AI answer systems.

## What good content optimization should produce

- clearer search intent match
- better title and heading structure
- stronger topical coverage
- better readability
- less keyword stuffing
- cleaner internal linking suggestions

## What to examine

- title
- meta description
- headings
- topical coverage
- entity coverage
- internal links
- schema opportunities
- AI-answer friendliness

## Useful outputs

- rewrite suggestions
- content brief
- page structure
- internal link plan
- FAQ ideas

## Human check

If the page is better for search but worse for a human, the optimization missed the point.
