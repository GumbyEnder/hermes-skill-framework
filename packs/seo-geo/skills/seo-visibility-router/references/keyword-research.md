
## Use this when

The user wants keyword ideas, clusters, topic expansion, or search-intent mapping.

## What good keyword work should produce

- a clean list of target terms
- intent groupings
- primary vs secondary terms
- content opportunities
- obvious gaps worth writing for

## What to look for

- high-intent commercial terms
- long-tail informational terms
- questions people actually ask
- terms that map to a page type
- variants that should not be split across too many pages

## Useful outputs

- keyword cluster table
- intent matrix
- page recommendations
- priority list
- cannibalization warnings

## Human check

If the keyword set does not lead to a page or workflow, it is probably too abstract.
