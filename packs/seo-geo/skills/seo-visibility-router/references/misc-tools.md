
## Use this when

The user is asking which tool should be used next, or when the task does not fit a single bucket cleanly.

## Useful categories of tools

- SEO suites
- keyword tools
- crawlers
- rank trackers
- content optimization tools
- local SEO tools
- social preview tools
- AI visibility tools
- performance tools

## What this reference is for

This is not a shopping list.
It is a practical reminder that a lot of SEO work is tool-agnostic until the workflow is clear.

## Human check

If the tool is the only thing being discussed and the workflow is still unclear, step back and define the workflow first.
