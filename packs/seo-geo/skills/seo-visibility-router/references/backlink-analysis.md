
## Use this when

The user wants link-building help, backlink analysis, authority planning, or competitor link gap ideas.

## What good authority work should produce

- a sense of how strong the site is relative to competitors
- link opportunities worth pursuing
- link types that actually matter for the niche
- obvious risk flags if the profile looks spammy

## What to look for

- referring domains
- anchor text patterns
- link quality vs quantity
- competitor mentions
- content worth earning links naturally

## Useful outputs

- backlink gap summary
- outreach targets
- content assets for link earning
- risk notes

## Human check

If the link opportunity is unlikely to earn a real citation or referral, it is probably noise.
