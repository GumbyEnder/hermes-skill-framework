
## Use this when

The user is dealing with crawl issues, indexation problems, render problems, structured data, speed, canonical problems, or sitemap/robots questions.

## What good technical analysis should produce

- a short list of actual issues
- the likely impact on visibility
- the safest fix order
- anything that needs developer attention

## What to examine

- robots.txt
- sitemap.xml
- canonical tags
- redirects
- status codes
- page rendering
- structured data
- internal linking
- crawl budget issues
- performance basics

## Useful outputs

- issue list
- fix priority order
- developer handoff notes
- verification checklist

## Human check

If the fix is more complicated than the problem, re-check the diagnosis.
